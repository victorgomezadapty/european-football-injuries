# Burden definitions

| Concept | Operational measure | Interpretation limit |
| --- | --- | --- |
| Occurrence | Count of retained source records | Includes non-injury absence and possible repeated episodes |
| Severity | Continuous reported days out per record | No categorical clinical cutoff; inclusive date convention |
| Match loss | Reported games missed per record | Fixture/eligibility reconciliation unavailable |
| Time-loss burden | Sum of valid nonnegative integral reported days | Episode sum; possible overlap and duplicate counting |
| Match-loss burden | Sum of valid nonnegative integral games missed | Episodes and club contexts can repeat the same matches |
| Recorded date union | Unique dates in valid inclusive intervals per name | Incomplete absence recording and no denominator |
| Frequency/severity matrix | Record count × median reported duration, bubble area for games | Descriptive comparisons, no individual risk |

All group sums have valid sample counts, and entirely missing outcomes remain unavailable. Group by source season/club context. Monthly burden is assigned to the onset month; it does not count actual absence days within that month.
